# ADR 002 — PostgreSQL as System of Record

## Context

سجلات الطلاب والتسجيلات والعضويات والسياسات والدرجات والنتائج تحمل علاقات وتاريخًا وقيودًا لا يمكن ضمانها بمصفوفات العميل أو مخزن وثائق عام.

## Decision

PostgreSQL هو مصدر الحقيقة الوحيد. تستخدم JSONB فقط للحمولات والقوالب وsnapshots الديناميكية؛ يبقى tenant والملكية والنطاق والحالات والإصدارات والممثل والزمن أعمدة علائقية مفهرسة. تُنفذ القيود التي لا يعبر عنها ORM بترحيلات SQL صريحة.

## Consequences

يمكن فرض foreign keys وpartial unique indexes وtriggers وtransactions واختبارها على قاعدة فعلية. تتطلب البيئة PostgreSQL ولا تستبدل SQLite في اختبارات سلامة البيانات.
