# ADR 010 — Versioned Academic Policies

## Context

المتطلبات وسياسات workflow والrubrics وصيغ النتائج تتغير، لكن التقييمات والإرسالات السابقة لا يجب أن تُفسر بالقواعد الجديدة.

## Decision

تدير المجاميع policy versions بالحالات draft/published/archived. تنشر الخدمة نسخة جديدة ولا تعيد كتابة المنشور، وتحفظ submission/assessment/result مرجع النسخة أو snapshot المطلوب. تمنع القيود وجود أكثر من نسخة requirements منشورة فعالة لنفس scope عندما لا يكون التوازي مقصودًا.

## Consequences

تؤثر السياسة الجديدة في العمليات المستقبلية فقط. تبقى عمليات publish/archive معاملات خادمية وأحداثًا تدقيقية؛ لا يتوفر generic edit للنسخة المنشورة.
